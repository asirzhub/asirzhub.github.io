# asirz.github.io

Simple GitHub Pages site for Asir Zaki.

## Project structure

- `index.html` — root landing page
- `styles.css` — page styles
- `img/` — image assets
- `fonts/` — custom font file

## GitHub Pages

This repository is set up as a user site (`asirz.github.io`). GitHub Pages will serve the site from the root of the default branch.

## Notes

- `.nojekyll` is included so GitHub Pages serves the files directly without Jekyll processing.
- `.gitignore` excludes common OS/editor files.
